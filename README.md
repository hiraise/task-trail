# TaskTrail

Открытый self-hosted трекер задач для небольших команд — лёгкий аналог YouTrack: проекты,
участники с ролями, задачи, комментарии, канбан-доски и поиск, без многодневной настройки.

Проект в разработке. Сейчас идёт этап 0 — сборка единого репозитория и правил работы.

## Структура

| Путь | Что там |
| --- | --- |
| `server/` | API на Go (Gin, PostgreSQL); история перенесена из `hiraise/tt-backend` |
| `web/` | Веб-клиент на React и TypeScript (Vite); история перенесена из `hiraise/tt-frontend` |
| `docs/adr/` | Архитектурные решения — [индекс](docs/adr/README.md) |
| `scripts/dev.sh` | Проверки и запуск |
| `CLAUDE.md` | Правила работы для AI-агентов |

## Разработка

Нужны Go (версия — в `server/go.mod`) и Node.js 22.

```bash
scripts/dev.sh check    # всё, что проверяет CI: правила, сервер, веб
scripts/dev.sh server   # только сервер: vet, тесты, golangci-lint
scripts/dev.sh web      # только веб: линтер, тесты, типы и сборка
```

Переменные окружения сервера — в [server/README.md](server/README.md).

## План

1. **Этап 0.** Единый репозиторий, правила и ADR, проверки и CI; локальный стенд и контракт API.
2. **Этап 1.** Сервер догоняет контракт, на котором работает веб-клиент.
3. **Этап 2.** Комментарии, доски, поиск, архив, ключи задач — ядро из [ADR-0004](docs/adr/0004-lightweight-youtrack-scope.md).
4. **Этап 3.** Приоритет, срок, метки, уведомления и остальное «после ядра».
5. **Этап 4.** Android-клиент.
