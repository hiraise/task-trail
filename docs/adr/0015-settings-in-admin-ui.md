# ADR-0015: Настройки сервиса — в интерфейсе администратора, в окружении — только то, без чего сервер не запустится

- **Статус:** Принято
- **Дата:** 2026-10-21
- **Затрагивает:** `server/config/config.go`, `server/internal/app/`, `server/internal/infrastructure/`, `server/internal/presentation/http/v1/`, `server/migrations/`, `server/README.md`, `stand/compose.yaml`, `scripts/dev.sh`, раздел администратора в `web/src/presentation/features/`, настройки в контракте API

## Контекст

Заказчик хочет настраивать TaskTrail в интерфейсе, включая интеграции, а не правкой `.env`
и перезапуском. Сейчас сервер читает 27 переменных окружения.

## Решение

- Переменные окружения — только для запуска. Обязательны две: `PG_CONNECTION_STRING`
  и `APP_SECRET`; сервер не запускается, если `APP_SECRET` короче 32 символов. Необязательны, со значением по умолчанию: `PORT`, `APP_ROOT_PATH`, `FILES_DIR`
  ([ADR-0013](0013-files-on-server-disk.md)), `APP_DEBUG`. Новая переменная — только через ADR.
- То, что администратор захочет поменять, — адрес сервиса, почта, интеграции — делай настройкой
  в интерфейсе администратора ([ADR-0014](0014-service-administrator.md)). Настройки хранятся
  в базе и действуют без перезапуска.
- Остальное — константы в коде: время жизни токенов, имена cookie, `iss`, размер пула соединений.
  Настройку «на всякий случай» не заводи.
- Миграции применяй при каждом запуске; файлы миграций встрой в бинарник (`embed`).
- Ключи подписи токенов и ключ шифрования выводи из `APP_SECRET` (HKDF с разными метками).
- Секреты интеграций (пароль SMTP, токены) храни в базе зашифрованными ключом из `APP_SECRET`
  (AES-GCM). API их не отдаёт — только признак «задан». Секрет, который не расшифровывается,
  считай не заданным: сервер работает, администратор вводит его заново.
- Сохранённый секрет отправляй только туда, для чего его ввели: сменились сервер или порт
  интеграции — секрет вводится заново.
- Адрес сервиса — полный адрес веба с путём, например `https://example.com/tasktrail`. Веб
  передаёт его при создании первого аккаунта, сервер проверяет, что это адрес http(s);
  администратор может его поменять. От него строятся ссылки в письмах и приглашениях.
- Новую интеграцию подключай так же: настройки и проверка подключения — в интерфейсе
  администратора, без новых переменных окружения.
- Стенд `scripts/dev.sh up` настраивает сервер через API администратора, а не окружением.

## Последствия

- Смена `APP_SECRET` завершает все сессии, а секреты интеграций придётся ввести заново.
- Резервная копия — база, папка `FILES_DIR` и `APP_SECRET`.

## Альтернативы

- Секрет, который сервер создаёт сам и хранит в базе, — нет: утёкшая копия базы позволила бы
  подделать сессию на живом сервере.
- Файл конфигурации вместо `.env` — та же правка руками и перезапуск.
