# Architecture decisions (ADR)

Architecture and important system decisions of the project. The project is built by AI agents,
so ADRs are written for them first — short, with checkable rules — and for people second.
When an ADR is needed — [CLAUDE.md](../../CLAUDE.md); how to write one and the template —
[template.md](template.md).

Statuses: `Proposed` → `Accepted` → `Superseded by` or `Deprecated`. Accepted ADRs are mandatory;
proposed ones wait for the customer's decision; superseded and deprecated ones are kept for
history — the ADR that superseded them is in force.
