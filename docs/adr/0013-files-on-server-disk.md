# ADR-0013: Файлы хранятся на диске сервера и отдаются через API

- **Статус:** Предложено
- **Дата:** 2026-10-21
- **Затрагивает:** таблица `files` в `server/migrations/`, загрузка и выдача файлов в `server/internal/`, `server/config/config.go`, `stand/compose.yaml`, `stand/nginx.conf.template`, загрузка аватарки в `web/src/`

## Контекст

Аватаркам, а на этапе 3 и вложениям, нужно хранилище. Старый API клал файлы в S3, а для
self-hosted это ещё один сервис при установке (принцип 2 в [CLAUDE.md](../../CLAUDE.md)).

## Решение

- Храни файлы в папке на диске сервера, путь задаёт `FILES_DIR`. В Docker это том.
- Имя файла на диске — `files.id`. Исходное имя и MIME-тип храни только в `files`;
  путь на диске из данных пользователя не строй.
- Тип определяй по содержимому файла, а не по заголовку запроса. Аватарка — JPEG, PNG или WebP
  до 5 МБ. Лимит размера держи одинаковым в сервере, вебе и прокси стенда (`client_max_body_size`).
- Отдавай файлы только через API, раздачи папки через nginx нет. Аватарку — по `files.id`
  без проверки входа: ID — случайный UUIDv4, а `<img>` не умеет обновить истёкший токен.
  Вложение — только участникам его проекта.
- Отдавай файлы с `X-Content-Type-Options: nosniff` и `Cache-Control: private, max-age=31536000,
  immutable`: файл по `files.id` не меняется. Всё, кроме JPEG, PNG и WebP, — с
  `Content-Disposition: attachment`, иначе HTML или SVG выполнит чужой скрипт на origin веба.
- Хранилище — интерфейс в `internal/domain`, реализация на диске — в `internal/infrastructure`
  ([ADR-0007](0007-server-architecture.md)).
- Не прошла транзакция — удали записанный файл. Ненужный файл (заменённая аватарка, удалённое
  вложение) помечай `files.soft_deleted_at`; периодическая очистка стирает его с диска и ставит
  `deleted_at`, а заодно стирает файлы старше суток, у которых нет записи в `files`.

## Последствия

- Резервная копия — дамп базы и папка `FILES_DIR` вместе. Будущий ADR о выпуске должен
  монтировать её томом.
- S3-совместимое хранилище можно добавить второй реализацией интерфейса — отдельным ADR.

## Альтернативы

- S3 (MinIO) по умолчанию — ещё один сервис для установки; небольшой команде хватает диска.
