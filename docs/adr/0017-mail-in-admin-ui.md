# ADR-0017: Почту подключает администратор в интерфейсе сервиса

- **Статус:** Принято
- **Дата:** 2026-10-21
- **Затрагивает:** `server/internal/infrastructure/service/notification/`, `server/internal/app/`, `server/cmd/`, `server/internal/presentation/http/v1/`, `web/src/presentation/features/auth/`, `web/src/presentation/features/projects/`, раздел администратора в `web/src/presentation/features/`, `scripts/dev.sh`, почта, приглашения и настройки в контракте API
- **Заменяет:** [ADR-0012](0012-optional-mail.md)

## Контекст

Внешние сервисы подключаются по желанию (принцип 2 в [CLAUDE.md](../../CLAUDE.md)), а настройки —
в интерфейсе ([ADR-0015](0015-settings-in-admin-ui.md)). От ADR-0012 отличается тем, что SMTP
задаётся не окружением, а администратором.

## Решение

- Почта включена, когда администратор ([ADR-0014](0014-service-administrator.md)) сохранил
  настройки SMTP: сервер, порт, шифрование (нет, STARTTLS, TLS), отправитель и, если нужны,
  логин и пароль. Без них сервер работает и писем не шлёт.
- Перед сохранением проверяй подключение; администратор может отправить себе тестовое письмо.
- С почтой ссылку приглашения ([ADR-0016](0016-invite-only-signup-first-admin.md)) отправляй
  только письмом. Без почты возвращай пригласившему в ответе API ссылку для каждой приглашённой
  почты — и при добавлении участников, и при создании проекта.
- Письма со ссылками — приглашение, сброс пароля — отправляй сразу в запросе: не ушло — верни
  ошибку отправки в ответе API (для приглашений — по каждой почте), а не только запиши в лог.
- Человека, которого добавили в проект сразу, с почтой извещай письмом, без почты — никак.
- Без почты эндпоинты, которым она нужна (`password/forgot`), отвечают ошибкой с отдельным кодом,
  а не успехом без письма.
- Без почты ссылку сброса пароля выдаёт администратор. Тому, кто управляет сервером, ссылку
  сброса для любой почты печатает команда сервера — на случай, когда ни один администратор
  не может войти.
- Ссылки строй от адреса сервиса (ADR-0015); переменных `FRONTEND_*` нет.
- Отдавай вебу без входа: включена ли почта и открыта ли регистрация. Веб прячет недоступные действия.

## Последствия

- В разработке почта уходит в Mailpit ([ADR-0010](0010-local-development.md)) без шифрования
  и без логина: его настройки сохраняет `scripts/dev.sh up` через API администратора, сертификаты
  и `SSL_CERT_FILE` на стенде не нужны.
