# ADR-0008: Веб — слои по образцу clean architecture, один адаптивный компонент на экран

- **Статус:** Предложено
- **Дата:** 2026-10-21
- **Затрагивает:** `web/src/`

## Контекст

Веб-клиент разделён на слои, но почти каждый экран написан дважды — `*Mobile` и `*Desktop`,
а выбирает между ними `DeviceBased` по ширине окна. Каждая новая функция удваивает работу.

## Решение

- Слои `web/src`: `domain` — модели и типы; `application` — сценарии; `infrastructure` — HTTP
  и репозитории API; `presentation` — компоненты и хуки; `routes` — маршруты TanStack Router;
  `shared` — общие утилиты, константы, тексты.
- Запросы к API — только через репозитории `infrastructure/repositories`.
- Новый экран или компонент — один, адаптивный через CSS на брейкпоинтах дизайна
  (393, 768 и 1200 px). Новых пар `*Mobile`/`*Desktop` и использований `DeviceBased` не добавляй.
- Меняешь экран, у которого есть пара `*Mobile`/`*Desktop`, — слей её в один компонент.
- Цвета, тени и шрифты бери из переменных `web/src/styles/globals.css`, а не задавай значениями.

## Проверка

`scripts/rules.mjs` — файлов `*Mobile.tsx` и `*Desktop.tsx` не больше, чем в прошлый раз:
порог только снижается.
