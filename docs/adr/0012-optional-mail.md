# ADR-0012: Почта подключается по желанию

- **Статус:** Принято
- **Дата:** 2026-10-21
- **Затрагивает:** `server/config/config.go`, `server/cmd/`, `server/internal/app/`, `server/internal/infrastructure/service/notification/`, `server/internal/presentation/http/v1/`, `web/src/presentation/features/auth/`, `web/src/presentation/features/projects/`, приглашения и настройки в контракте API

## Контекст

По принципу 2 в [CLAUDE.md](../../CLAUDE.md) внешние сервисы подключаются по желанию, а сервер
не запускается без настроек SMTP.

## Решение

- Включай почту, только если задан `SMTP_HOST`. Без него сервер запускается и писем не шлёт;
  остальные `SMTP_*` обязательны только вместе с `SMTP_HOST`.
- С почтой отправляй ссылку приглашения ([ADR-0011](0011-invite-only-signup.md)) только письмом.
  Без почты возвращай пригласившему в ответе API ссылку для каждой приглашённой почты —
  и при добавлении участников, и при создании проекта.
- Человека, которого добавили в проект сразу, с почтой извещай письмом, без почты — никак.
- Без почты эндпоинты, которым она нужна (`password/forgot`), отвечают ошибкой с отдельным кодом,
  а не успехом без письма.
- Без почты пароль сбрасывает тот, кто управляет сервером: команда сервера печатает ссылку сброса
  для указанной почты. Команда работает и с почтой.
- Ссылки строй от `FRONTEND_URL` и путей веба; `FRONTEND_VERIFY_URL`,
  `FRONTEND_RESET_PASSWORD_URL` и `FRONTEND_PROJECT_URL` удали.
- Отдавай вебу настройки: включена ли почта и открыта ли регистрация. Веб прячет недоступные действия.

## Последствия

- Без почты человек не восстановит пароль сам — только через того, кто управляет сервером.
- В разработке почта по-прежнему уходит в Mailpit ([ADR-0010](0010-local-development.md)).
